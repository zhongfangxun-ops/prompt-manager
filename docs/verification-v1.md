# Windows x64 首版验收

## 本机测量

Windows 11 10.0.26200，144 DPI（150%），UCRT64 Release x64。使用临时资料库，含 1000 条常规提示词、额外一条长文、20 个标签。打开窗口的测量含选中长文的预览和首次绘制，操作系统文件缓存在各轮之间保留。完整采样保存在 [JSON 记录](measurements/v0.1.0.json)。

| 状态 | 私有字节数中位数 | 工作集中位数 | 60 秒 CPU 时间增量 |
|---|---:|---:|---:|
| 仅托盘和胶囊 | 1.86 MiB | 12.61 MiB | 0.000 秒 |
| 打开管理窗口 | 5.60 MiB | 23.61 MiB | 0.000 秒 |
| 打开一次并收起 | 2.83 MiB | 20.87 MiB | 0.000 秒 |
| 连续开关 30 次后收起 | 4.05 MiB | 21.82 MiB | 0.000 秒 |

最终采样时默认桌面的全屏窗口触发了胶囊自动隐藏。另在独立 Windows 桌面上确认胶囊可见，持续 15 秒采样，后台私有内存中位数 1.82 MiB，工作集 11.03 MiB。

四种状态使用独立测试实例，进入状态后静置 60 秒，再采样 60 秒。30 次开关的第 1、10、20、30 次，关闭窗口后即时检查的 GDI 句柄均为 25，USER 句柄均为 23。「0.000 秒」表示该采样窗口的进程计数器未记录到增量。此前两轮的仅后台私有内存分别为 2.25 和 2.50 MiB，Windows 的内存回收和桌面状态会影响结果。

| 操作 | 样本 | 中位数 | P95 |
|---|---:|---:|---:|
| 独立进程首次打开已有库 | 20 | 200.53 ms | 221.67 ms |
| 收起后再次打开 | 20 | 172.57 ms | 187.20 ms |
| 分类内输入关键词并刷新列表 | 36 | 19.44 ms | 28.84 ms |

首次建空库并打开一次耗时 83.30 ms。原实现再次打开的中位数为 316.99 ms。排查发现大段正文在文本控件获得最终宽度前就被载入，产生额外排版；调整首次布局和预览载入顺序后再测。采样使用发布 exe，包含对带边框铺满屏幕窗口的全屏识别修正。

## 功能验证

- CTest 包含六个测试，分别覆盖锚点、存储与事务回滚、组合查询和最近使用排序、剪贴板换行、复制手势以及胶囊透明通道。
- 用含中文和空格的独立目录运行发布 exe，并从 PATH 移除 MSYS2。真实窗口走过新建、加两个标签、分类与全文搜索、编辑、重新打开和删除。
- 专门锁住 SQLite 后从关闭对话框选择保存，确认写入报错后草稿仍在，解除锁后可直接保存。给标签框发送中文输入法组合消息，验证 Enter 和 Esc 交由输入法处理。
- Windows 登录启动开关采用临时测试项核对写入和移除；托盘入口、二次启动复用、关闭回后台、退出进程和手动隐藏胶囊后的恢复均有检查。实际注销登录未做。
- Windows CI 使用独立虚拟机验证真实剪贴板、占用失败后的重试、复制后的精确文本和双击保护。发布提交还通过了跨进程粘贴到 Windows 记事本后逐字符核对，以及真实前台测试窗口全屏、恢复、手动隐藏优先的检查。[该次 Windows CI](https://github.com/zhongfangxun-ops/prompt-manager/actions/runs/44798138188)。可在[仓库的 Windows 构建记录](https://github.com/zhongfangxun-ops/prompt-manager/actions/workflows/windows.yml)查看每次提交的结果。
- 抽查发布 exe 的 PE 导入列表，运行依赖来自 Windows 系统。便携包随附静态链接组件的许可证。
- [管理窗口实拍](images/library.png)与[编辑窗口实拍](images/editor.png)使用合成示例数据。[胶囊样图](images/edge.png)以实际绘制代码生成普通态、悬停态，并合成在三种测试背景上。

## 现场覆盖范围

自动化覆盖工具的窗口路径和单屏几何。独占全屏游戏、外接屏拔插、真实混合 DPI 双屏以及各厂商中文输入法的候选窗体验，仍需对应硬件或软件现场验证。本机后段测试环境限制了访问桌面剪贴板，真实剪贴板的集成检查在 GitHub Windows 测试机上完成。
