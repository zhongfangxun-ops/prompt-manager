# Windows 提示词管理器 · 首版实施方案

> 执行指引：使用 Superpowers 的 `executing-plans` 逐项实施，也可以按用户选择使用 `subagent-driven-development`。实施结果见[首版验收记录](../../verification-v1.md)。复选框保留待现场验证的项目。

**目标**　在其他应用里写到一半时，用户可以从屏幕边缘打开本地提示词库，按分类或关键词找到条目，复制保留原格式的正文，然后继续写作。

**架构**　一个 Windows 桌面进程运行一个消息循环。托盘和贴边胶囊随进程启动，第一次打开管理窗口时才打开资料库、创建管理控件和加载列表。收起后销毁管理窗口，释放列表、正文和数据库连接，保留托盘与胶囊。

**技术栈**　C++20、Win32、Windows Common Controls、GDI+、SQLite、CMake、Ninja、CTest。目标机器为 Windows 11 x64。本机已找到 MSYS2 UCRT64 的 g++、Ninja、SQLite 头文件和静态库，以及 CMake 4.2.3。构建和性能测试是后续实施任务。

**设计依据**　[已确认的产品规格](#已确认的产品规格)收录在本文件中。工程默认值、外观尺寸和性能预算均为本方案建议，便于试用后调整。

## 已确认的产品规格

| 场景 | 用户应看到的行为 |
|---|---|
| 日常桌面 | 屏幕边缘有一枚可拖动的悬浮按钮。点一下打开完整管理窗口，也可以将入口收进系统托盘。 |
| 全屏 | 视频、演示或游戏进入全屏时入口自动隐藏，退出后回到先前位置。 |
| 浏览 | 左边搜索、切换分类和选标题，右边阅读完整正文。阅读时可以选中文字，主动点击「编辑」后才修改内容。 |
| 分类 | 每条可挂多个标签。一次选一个分类，列表只显示属于它的条目。「全部」恢复整个库。保存时可以创建标签，也可以暂不归类。 |
| 搜索 | 打开浏览窗口时搜索框获得焦点。关键字匹配标题和正文，与当前分类叠加。默认按最近使用排列。 |
| 管理 | 新建、编辑、删除。标题由用户填写，标签可选。点击行旁的复制按钮只复制正文，保留换行、缩进和空行。 |
| 复制与退出 | 点击复制后给出「已复制」反馈，窗口保持打开。浏览时按 Esc 收起。用户可以从托盘彻底退出。 |
| 运行与视觉 | 本地独立保存，支持开机启动开关。Liquid Glass 风格用于贴边胶囊和工具栏，正文使用实色底。 |

## 全局约束与工程取舍

- 应用的运行、存储和搜索全在本地完成。单用户、单实例。工作目录暂用 `D:\codexproject\prompt-manager`，界面标题暂用「提示词」。
- 常驻层以系统消息驱动；空闲时停掉动画与反馈计时器。胶囊不抢输入焦点，用户主动打开管理窗口时才把焦点给搜索框。
- 采用原生窗口以直接控制常驻资源。代价是要自行做好控件排版、缩放和玻璃材质。第一阶段先在实际桌面验证胶囊，再投入完整界面。
- SQLite 采用 UCRT64 的同一套头文件和库；发布时首选静态链接 SQLite。保留标准编辑控件的中文输入法、文本选择、撤销和辅助功能。
- 每项交付用独立提交记录；执行时若新项目尚无 Git 仓库，先在项目目录初始化本地仓库。发布物为本机可直接运行的 x64 便携包。

## 界面与交互细节

**桌面入口。** 初始放在主屏右边缘中央，建议点击区域 36 × 52 DIP。胶囊采用半透明填充、细边缘高光和居中图标；鼠标移入时略微提亮。使用预乘透明度的小位图按状态绘制，只在状态、尺寸或主题变化时更新。首样要分别放在浅色壁纸、深色壁纸和复杂照片上看。透明与边缘高光属于首版材质范围，动态背景折射留给实际视觉评审后决定。微软提供分层窗口的逐像素透明能力，苹果的设计指南将玻璃材质用于控件和导航。[Windows 分层窗口](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features) · [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

**管理窗口。** 默认尺寸建议 900 × 580 DIP，按当前屏幕工作区收窄。左栏约占三分之一，依次为搜索框、单选分类、标题列表。标签多时允许横向浏览并保留可见的溢出入口。每行保留明确的复制按钮，点标题只切换右侧预览。右栏以标题、标签、可选择的正文为主，工具栏提供「新建」「编辑」，删除放进条目菜单。初版使用系统中文界面字体，正文建议 15 DIP。高对比度环境采用系统配色，所有操作均可用键盘到达。

**新建和编辑。** 同一个编辑面板承载标题、正文、标签以及「保存」「取消」。保存时要求标题、正文各至少有一个非空白字符；正文按输入原样存储。输入标签后按 Enter 加入，可点掉已有标签。保存后回到详情；如果当前筛选会遮住刚保存的条目，切到「全部」并清空搜索，选中刚保存的条目。关闭有改动的编辑面板时给「保存／放弃／继续编辑」。删除前展示条目名，确认后删除。空库显示「新建第一条提示词」，有库无匹配显示「没有匹配的提示词」，提供清除筛选的入口。

**默认值。** 建议开机启动初始关闭，打开开关后于下次登录生效；自动启动只显示常驻入口。每次重新打开浏览窗口从「全部」、空搜索开始。成功复制才计入「最近使用」，只预览或复制失败都保持原顺序。未使用条目排在已使用条目后，按创建时间倒序。剪贴板被占用时说明「复制失败，请重试」，保留当前位置。编辑时 Esc 先处理编辑状态，浏览时才收起整个窗口。

## 数据和持久化

| 位置或表 | 数据与约束 |
|---|---|
| `%LOCALAPPDATA%\PromptManager\library.sqlite3` | 第一次打开管理窗口时创建。用 `PRAGMA user_version` 标识结构版本，V1 为 1。 |
| `prompts` | `id INTEGER PRIMARY KEY`，`title`、`body`、`created_at`、`updated_at`、可空的 `last_used_at`。时间统一为 UTC 毫秒，时间相同用 id 倒序稳定排序。 |
| `tags` | `id`、`name`。去掉首尾空格，空标签忽略，英文大小写视为同一标签，保留首次显示写法。 |
| `prompt_tags` | `prompt_id, tag_id` 组成联合主键，两侧设外键，并给按 tag 查找建立索引。每次连接启用外键。 |
| 当前用户注册表 | `HKCU\Software\PromptManager` 保存入口显示偏好、屏幕标识、吸附边和沿边相对位置。登录启动采用当前用户 Run 项，写入带引号的 exe 路径。界面读取真实启动项状态。 |

一次保存用一个事务更新正文和标签关联。删除条目时一并清理关联；最后一个引用消失后移除空标签。搜索采用绑定参数的字面子串匹配，中文可匹配词中片段，英文忽略 ASCII 大小写，百分号和下划线按普通字符处理。列表查询只返回标题、ID 等摘要；选中条目后单独读取正文。预览和复制沿用同一正文来源。Windows 剪贴板采用 Unicode 文本，行分隔按 Windows 文本约定转换，保留逻辑行、空行、前后空格和制表符。

## 优先评审的五类问题

1. 用户拖动或拔掉外接屏后，胶囊还应出现在可见位置；手动收起后，退出全屏也应尊重这个偏好。由任务 2 检查。
2. 正文含中文、表情、代码缩进或连续空行，保存、重启、再复制后应保留内容。由任务 3、5 检查。
3. 同一条属于两个分类，切换分类再搜索，结果、选中项和右侧正文应保持一致。由任务 4 检查。
4. 剪贴板繁忙或保存事务中途失败，应保留原数据、草稿和可重试的入口。由任务 3、5 检查。
5. 长提示词库开关窗口多次后，常驻内存和图形句柄应趋于稳定。由任务 6 检查。

## 性能验收与发布判断

以下数值是**待实测的工程预算**。统一测 Release x64。工作集会受 Windows 回收策略影响，内存预算按进程私有字节数判断，同时报告工作集供任务管理器对照。

| 项目 | 首轮目标 | 判断方法 |
|---|---:|---|
| 登录后仅常驻 | 私有字节数中位数 ≤ 20 MiB | 含托盘与可见胶囊，尚未打开管理窗 |
| 打开后再次收起 | 私有字节数中位数 ≤ 30 MiB | 加载 1000 条后收起；重复 30 次观察是否持续爬升 |
| 空闲 CPU | 60 秒内进程 CPU 时间增量 ≤ 0.12 秒 | 相当于平均占用单个逻辑核心 0.2%；避开测量期间鼠标悬停和窗口切换 |
| 首次打开 | 中位数 ≤ 350 ms，P95 ≤ 600 ms | 20 次独立进程启动后首次点开；文件系统缓存条件单列 |
| 再次打开 | 中位数 ≤ 200 ms | 同一进程关闭管理窗口后重新打开，至少 20 次 |
| 分类内搜索 | 1000 条下 P95 ≤ 100 ms | 至少 30 次切换中文词、英文词、无匹配词，含列表刷新 |

若超出预算，先定位耗时或内存归属。启动阶段重点看是否提前读库或创建管理控件；打开阶段区分 SQLite 查询、控件创建和首次绘制；收起后检查文本缓冲区、窗口句柄和绘图资源。复测后把原值、改动和新值一起记录。
